# Historical research archive rules

Read the root `AGENTS.md`. This directory retains historical methods and evidence for provenance.
It is not the standalone runtime, an executable dependency, or a source of current performance
claims. Keep dates, workload, hardware, metric definitions, and limitations alongside any result.
Do not rerun retired scripts or copy old class-ID conventions into Drishti. If redacting an
identifier, preserve numerical data and note that the original artifact remains in Git history.
New research belongs in `docs/research/`.
