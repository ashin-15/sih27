# Run evidence rules

Read the root and package `AGENTS.md`. Saved manifests, frame records, summaries, and recordings
are evidence tied to one command, code state, dataset, and configuration. Create a new unique
output directory for each run. Do not overwrite, clean, or repair existing reports to make a
claim pass. If a report is absent or modified, record its status as NOT VERIFIED and keep the
provenance gap visible. Distinguish synthetic from real-data runs and logical payload bytes from
process or viewer memory.
