What exists today, and what the full perception pipeline still needs

The active package is a tested single-frame LiDAR mapper. The seven requested perception and real-time capabilities are planned work, with no implementation claim yet.

Current execution

Single frame

Ground, range projection, adaptive cell aggregation, report, optional Rerun view.

Verification

42 tests passed

Three synthetic frames completed. No real-data or full-path benchmark was run here.

Release gate

False

The code records a 100 ms budget, but does not claim a real-time guarantee.

Capability ledger

Seven missing pieces and their first proof

CapabilityCurrent evidenceFirst required proof
Learned semanticsGeometric mode assigns unknown; oracle copies labels.Checkpoint-backed per-point inference, aligned to original IDs, held-out mIoU.
Obstacle detectorNonground cell height envelope only.Object instances, bounds and class/unknown; thin-object and overhang fixtures.
Temporal fusionNo previous snapshot is read.Pose-aligned bounded state with age, conflict, reset and replay tests.
Object trackingOracle instance IDs do not enter mapping.Track lifecycle across crossing, occlusion and reappearance.
Motion estimationUnknown or oracle moving flag, no velocity.Ego-motion compensated velocity and unknown-on-insufficient-evidence behavior.
Free-space proofProjection records winners, not ray freespace.Occupied/free/unknown contract; no-return and occlusion cannot become free.
Real-time gateBudget field exists; release gate stays false.Complete-path target-hardware p99/max, misses, drops and memory.

Build sequence

  1. Freeze point, class, pose, time and acceptance contracts.
  2. Integrate and evaluate a versioned semantic model.
  3. Add obstacle observations, then track and measure motion.
  4. Add conservative rays and a bounded temporal map.
  5. Extend reports/viewer; profile the complete target path.

Task IDs T-001 to T-009 in docs/execution-plan.md.

Decisions still needed

  • D-001 Target hardware, deadline and allowed miss rate.
