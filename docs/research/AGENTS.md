# Research rules

Read the root and `docs/AGENTS.md` first. Each research effort starts from a numbered question
in `questions.md` and a module in `modules.md`. Record source date and provenance in
`evidence.md`; inspect primary papers, official dataset/evaluator documentation, or source code.
Search snippets and proposed designs are leads, not evidence.

Write a dated entry in `research-log.md` even when a candidate fails or the conclusion stays
UNKNOWN. Separate measured results from literature claims and hypotheses in `claims.md`.
Translate a finding into `implementation-impact.md` only when it changes or confirms a concrete
task or interface. Record experimental data, configuration, hardware, workload, and reproduction
steps under `experiments/`; never import historical prototype numbers as Drishti results.
